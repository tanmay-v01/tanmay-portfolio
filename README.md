# Tanmay Vaity — Product & UI/UX Designer Portfolio

A high-performance, responsive personal portfolio web application crafted for **Tanmay Vaity** (Product & UI/UX Designer), featuring interactive 3D studio mockups, transparent animated video hero avatars, case studies, clean interactive CV/resume, and an architectural design gallery.

---

## ✨ Features

- **Dynamic Hero Avatars**: Smooth transparent WebM/MP4/WebP video integrations with seamless looping micro-interactions.
- **Architectural 3D Studio Gallery**: Custom-rendered studio mockups for flagship client programs:
  - *Avaada CleanTech* (Renewable Enterprise Telemetry)
  - *Pastel Luxury Fragrance* (Travertine & Amber E-Commerce POS)
  - *Qlytic AI Data Observability* (Basalt & Cobalt AI Telemetry)
  - *Yo! Sports Tournament Platform* (Dynamic Neon & Glass Community Hub)
  - Social media designs, campaign banners, and vector assets with full-screen lightbox inspection.
- **Interactive Clean CV**: Minimalist, spaced curriculum vitae covering end-to-end design tenure, design systems, and tooling proficiencies.
- **Mobile-First Responsive Architecture**: Fluid layouts, drawer menus, and responsive typography ensuring zero visual regression between desktop and mobile.
- **Performance Optimized**: Zero layout shifts, lazy-loaded media, and optimized assets.

---

## 🛠 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Custom Design Tokens (`app/globals.css`)
- **Icons**: Lucide React
- **Video & Media**: WebM (VP9 with Alpha), H.264 MP4 fallback, Animated WebP posters

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/tanmayvaity-code/tanmay-portfolio.git
cd tanmay-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
